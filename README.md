## 🌟 這個 Repository 在做什麼？

這裡收藏獨角仙妹妹的讀題分析漫畫。

我們的目標不是把每一課的答案背熟，而是建立一套可以帶到國語、自然與社會的閱讀方法，讓妹妹遇到長題目時，能夠：

- 把長文字切成小段
- 每讀一段就抓出重點元素
- 看見原因、結果、比較、順序與轉折
- 分辨文章明說的內容與自己的推測
- 把詞語放回句子判斷意思
- 找到支持答案的證據

當題目看起來很多、很亂時，先不要急著放棄。

> **沒關係，我先讀一小段。**

---

## 🧭 共同讀題模型

```text
問：題目到底要我找什麼？
↓
切：把長題目切成小段。
↓
圈：圈出人物、事件、條件、轉折與重要小字。
↓
畫：把原因、結果、順序與比較畫出來。
↓
證：回到文章或資料找證據。
```

妹妹逐段閱讀時，使用更短的口訣：

> **讀 → 停 → 抓 → 連**

- **讀**：一次只讀一小段。
- **停**：確認腦袋跟上眼睛。
- **抓**：這段在說誰？發生什麼？重要條件與結果是什麼？
- **連**：這段和上一段是什麼關係？

## 📚 第五部分｜十二課讀題訓練

這一區不是課文摘要，而是把每課轉成可以帶到其他文章的讀題模型。

### 27｜第一、二課

遇見自己：看見什麼 → 感受什麼 → 想到什麼。  
為什麼大家不理我：人物行動 → 他人反應 → 原因。

![27 第一二課](27-G-1-2-lessons.png)

### 28｜第三、四課

孔子說的話：抽象道理 → 自己的話 → 生活例子。  
向大自然學習：觀察 → 發現特點 → 人類應用。

![28 第三四課](28-G-3-4-lessons.png)

### 29｜第五、六課

樹：分辨觀察、想像與觀點。  
善用自嘲，展現幽默：觀點 → 例子 → 證明。

![29 第五六課](29-G-5-6-lessons.png)

### 30｜第七、八課

公共藝術：名稱、地點、特點、功能不要混在一起。  
街頭藝術家：行動 → 證據 → 人物特質。

![30 第七八課](30-G-7-8-lessons.png)

### 31｜第九、十課

孫翠鳳和歌仔戲：問題 → 回答 → 重點 → 時間線。  
過故人莊：把古詩變成可以看見的畫面。

![31 第九十課](31-G-9-10-lessons.png)

### 32｜第十一、十二課

走一段海岸：景物 → 感受 → 思考。  
存根：物品 → 事件 → 轉折 → 意義。

![32 第十一十二課](32-G-11-12-lessons.png)
