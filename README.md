## 🌟 這個 Repository 在做什麼？

這裡收藏獨角仙妹妹的讀題分析漫畫。目標不是背熟答案，而是建立一套能帶到國語、自然與社會的閱讀方法：

- 把長文字切成小段
- 抓出人物、事件、條件與結果
- 看見原因、比較、順序與轉折
- 分辨資料、觀察、推測與意見
- 回到文章、圖表或實驗結果找證據

> **沒關係，我先讀一小段。**

---

## 🧭 共同讀題模型

```text
問：題目到底要我找什麼？
↓
切：把長題目切成小段。
↓
圈：圈出人物、事件、條件、轉折與重要小字。
↓
畫：把原因、結果、順序與比較畫出來。
↓
證：回到文章或資料找證據。
```

# 🌟 希望最後形成的自動路徑

```text
讀一小段 → 停一下 → 抓重點 → 畫關係 → 確認問題 → 找到證據
```

## 🎒 最後記住

當妹妹再次遇到長題目，希望腦中出現的不是「好多字，我看不懂」，而是：

> **沒關係，我先讀一小段。**  
> **這段重點是什麼？**  
> **題目問什麼？**  
> **證據在哪裡？**
